# AutoDocBG

**Vehicle inspection booking platform for Bulgaria**

Role: Product collaboration · Status: Pre-launch

AutoDocBG is a friends' venture. I helped shape it from a problem I'd experienced first-hand while living in Bulgaria into a launch-ready product — defining what it should do, how users should move through it, how the platform should be structured, and how it should be taken to launch.

The website and apps were developed by an external agency.
